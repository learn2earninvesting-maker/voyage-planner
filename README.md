# Voyage Fuel & ROB Planner

Installable web app (PWA) for voyage fuel-consumption, ROB and bunker planning.

- LSMGO in ECA / VLSFO outside ECA, port stays and drydock on LSMGO
- Running physical ROB, chained ETA/ETD, safety margin kept as usable fuel
- Bunker-supply check and "set lift to exact requirement"
- Route builder: free searoute network + approximate ECA split. **For bunker estimates only, not for navigation.**
- Works offline after first open; all voyage data stays on the user's device

Open the site, then use **Install app** (or the browser's Add to Home Screen / Install option).
